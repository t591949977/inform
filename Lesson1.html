Описание языка 1C Для облегчения написания операторов можно воспользоваться шаблоном. Для этого пишем 4 буквы оператора и нажимаем клавиши Ctrl+Q. Запускается мастер шаблонов. Для редактирования шаблонов заходим в меню Сервис/Шаблоны_текста. Имеется возможность включить автоматическую подсказку от шаблонов, для этого заходим в меню Сервис/Параметры и в окне Модули/Редактирование выставляем Автозамена: Включить с подсказкой. Тогда при наборе 4 букв команды появляются возможные варианты необходимо нажать Энтер или пробел и в появившемся окне выбрать желаемое. Коментарии Для автоматического ввода символа комментария // имеется специальная клавиша в меню, которая позволяет закомментировать несколько выделенных строк одновременно. Или снять комментарии с выделенных строк. • Переменные В языке переменные не обязательно объявлять в явном виде. Неявным определением переменной является первое ее появление в левой части оператора присваивания. Область видимости переменных зависит от места их определения. Существует три области, в которых можно объявить переменные: · В разделе определения переменных глобального программного модуля. Если переменные определены с ключевым словом Экспорт , то это будут глобальные переменные. Перем А, В, С Экспорт · В начале модуля, в разделе определения переменных модуля. Перем А, В, С; Процедура Кнопка1Нажатие(Элемент) · В процедуре или функции. Это локальные переменные. Процедура Кнопка1Нажатие(Элемент) Перем А, В, С; Глобальные переменные доступны для использования в исполняемых операторах, выражениях, в любой процедуре и функции любого программного модуля конфигурации задачи. Переменные модуля доступны для использования в исполняемых операторах, выражениях, в любой процедуре и функции того программного модуля, в пределах которого они объявлены. Локальные переменные доступны в пределах той процедуры или функции, в которой они объявлены. Строковые переменные Литералы строкового типа представляют собой набор символов, заключенных в кавычки. Для задания в строке символа « (кавычка) необходимо записать две кавычки подряд. Для многострочных строковых переменных в начале каждой следующей строчки ставиться знак | или каждая строка берется в кавычки, а двоеточие ставиться только после последней строки. Например: Текст = "Пробная запись" "многострочной строки"; Или Текст = "Пробная запись |многострочной строки"; Строки можно складывать, например Текст = "Пробная"+"строки"; Для вставки в строковую переменную кавычек необходимо набрать двойные ковычки Текст = "Пример "" кавычек"""; Числовые переменные Целочисленное деление % например 10%3 получим 3. Переменные даты Сперва указывается год месяц день час минуты сикунды. Дата='20110315'; Дата='2011.03.15'; Дата='2011.03.15.10.05.00'; Вместо точки можно использовать любой разделитель. Можно использовать функцию: Дата=Дата('2011, 03, 15'); Все параметры через запятую Операции сложения прибавляет к дате указанное количество секунд например Дата = Дата('2011, 03, 15') + 44; Булевые данные Иногда при проведении операций используют цифровое представление булевых данных – все что больше или равно 1 это истина, а 0 ложь. В арифметических выражениях в которых используются различные типы данных, программа анализирует тип первой переменной и старается все остальные привести к этому типу. Например: получим числовое значение х = 14 +”15” получим строковую переменную х = ”15”+14 Имеется возможность преобразования типов данных и через функции. Проверка типа переменной Для проверки типа переменной можно воспользоваться: Если ТипЗнч(ИспытуемаяПеременная) = Тип("Число") Тогда КонецЕсли; Функции преобразования типов Функции преобразования типов позволяют выполнять конвертацию одних типов данных в другие. Для преобразования типов используются одноменные функции: o Дата() o Строка() o Число() При преобразовании числа из 4 цифр в строку между группами чисел добавляется пробел. При стандартных региональных настройках для русского языка при приведении числа к строке между группами разрядов чисел вставляется неразрывный пробел (Символы.НПП), например: Год = 2003; Строка1 = Строка(Число1); //Строка1 = "2 003", длина строки - 5 символов, включая неразрывный пробел Чтобы преобразовать число к строке без вставки символа-разделителя групп (неразрывного пробела), нужно применить функцию Формат с параметром ЧГ=0: Строка1 = Формат(Число1,"ЧГ=0"); Для получения строкового представления года следует не получать числовое значение года, а использовать функцию Формат. Например: Формат(ТекущаяДата(), "ДФ=yyyy") Смотрите также на ИТС "Особенности форматирования значений". Коллекции (массивы, структуры) К коллекциям относятся массивы и структуры. Для объявления массива или Структуры необходимо использовать слово Новый. Массив Если при создании массива указывается максимальное количество его элементов, то такой массив называется статическим. Счет количества элементов в массиве начинается с 0, поэтому в следующем примере 4 элемента. Во время создания массива я сразу указал верхнюю границу элементов. Изменить это значение в процессе работы с массивом уже будет нельзя. А = Новый Массив(3); // в скобках нужно указать максимальное количество элементов в массиве. А[0]= 12; А[1]= Истина; А[2]= “Строка”; А.Добавит(132); С динамическими массивами все наоборот. Во время их создания не нужно указывать максимальное количество элементов. Просто инициализируем переменную типа массив и сразу можем добавлять в нее любое количество значений. Посмотрим пример: Массив = Новый Массив(); Массив.Добавить(1); Массив.Добавить(2); Массив.Добавить(3); Для перебора элементов массива, необходимо: Для сч = 0 по Массив.Количество() – 1 Цикл Сообщить(Массив[сч]); КонецЦикла; Примеры: Массив = Новый Массив(4); Сообщить("Количество: "+Массив.Количество()); Сообщить("Наибольший индекс массива: "+Массив.ВГраница()); Массив.Удалить(2); Сообщить("Количество после удаления: "+Массив.Количество()); // Этот элемент массива имеет тип Строка: Массив.Добавить("Добавили строку"); // Этот элемент массива имеет тип Число: Массив.Добавить(123.45); Сообщить("Количество после добавления: "+Массив.Количество()); // Добавим элемент по индексу, большему, чем ВГраница(): Массив.Вставить(8,"Метод добавил 4 новых элемента"); Сообщить("Количество после добавления: "+Массив.Количество()); // Массив может хранить разные типы данных: Сообщить("Типы элементов: "+Символы.ПС+ " Для 3-го элемента: "+ТипЗнч(Массив[3])+Символы.ПС+ " Для 4-го элемента: "+ТипЗнч(Массив[4])+Символы.ПС+ " Для 5-го элемента: "+ТипЗнч(Массив[5])); Массивы бывают одномерные и многомерные. Вышеприведенные примеры демонстрировали одномерные массивы, т.е. массивы с одним измерением. В многомерных массивах каждый элемент является ссылкой на другой одномерный массив. Пример: МногомерныйМассив = Новый Массив (2, 4, 10); В этом примере я объявил массив из двух элементов, каждый из которых является массивом из 4 элементов, каждый из которых является массивом из 10 элементов. Массив является линейной динамической коллекцией с произвольным типом значений. Поэтому значениями массива могут выступать другие массивы. То есть создание массивов и решает задачу создания многомерного массива. Рассмотрим пример массива состоящего из трех массивов, каждый по 8 элементов. ТрехмерныйМассив = Новый Массив (3, 8); ТрехмерныйМассив[0][3]=2; ТрехмерныйМассив[1][0]=Истина; ТрехмерныйМассив[0][3]=32; ТрехмерныйМассив[0][7]="Привет"; а=ТрехмерныйМассив[0][3]; в=ТрехмерныйМассив[1][0]; с=ТрехмерныйМассив[0][3]; д=ТрехмерныйМассив[0][7]; Или через добавление элементов ДвумерныйМассив = Новый Массив; МассивВторогоПорядка = Новый Массив (8); ДвумерныйМассив.Добавить(МассивВторогоПорядка); ДвумерныйМассив.Добавить(МассивВторогоПорядка); И в том и в другом случае мы решим задачу создания двумерного массива размерностью 2х8. Чтение и запись значений такого массива можно производить посредством директивного указания индексов или при помощи метода Получить(). Значение = ДвумерныйМассив[2][5]; или Значение = ДвумерныйМассив.Получить(2).Получить(5); Но использовать многомерные массивы в 1С очень неудобно, намного более практично использовать Таблицы значений. Видимость массива так же зависит от места объявления. Массивы объявленные в процедуре доступны только в этой процедуре, если нужно объявить массив доступный в пределах целого модуля или глобально, то сперва объявляется переменная (глобальная или в начале модуля) , а затем в одной из процедур модуля объявляется массив с таким же именем как у переменной, и в дальнейшем он имеет свойства видимости, как у переменной. Пример: Перем МойМассив; Процедура Кнопка5Нажатие(Элемент) в=МойМассив[1]; КонецПроцедуры Тот же принцип можно использовать для доступа к данным других перечислений, например Таблицы значений: Перем ТабЗнач; Процедура Кнопка1Нажатие(Элемент) ТабЗнач = Новый ТаблицаЗначений; ТабЗнач.Колонки.Добавить("Назван1"); ТабЗнач.Колонки.Добавить("Назван2"); НоваяСтрока = ТабЗнач.Добавить(); НоваяСтрока.Назван1 = "Значение1"; НоваяСтрока.Назван2 = "Значение2"; НоваяСтрока = ТабЗнач.Добавить(); НоваяСтрока.Назван1 = "Значение3"; НоваяСтрока.Назван2 = "Значение4"; КонецПроцедуры Процедура Кнопка2Нажатие(Элемент) Для Каждого ТекущаяСтрока Из ТабЗнач Цикл Сообщить(ТекущаяСтрока.Назван1); КонецЦикла;
